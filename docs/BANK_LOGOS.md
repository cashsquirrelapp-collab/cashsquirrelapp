# Bank logos (frontend/public/banks/)

Each bank's logo is that bank's own trademark, shown only to say which bank an account or a document belongs to.
Every file is a 96 × 96 round PNG made from the source below and kept locally (nothing is loaded from elsewhere).

| Files | Source | Terms |
| --- | --- | --- |
| BAAC, BAY, BBL, CIMB, GHB, GSB, ICBC, ISBT, KBANK, KKP, KTB, LHBANK, SCB, TISCO, TTB, UOB (2026-10-08); CITI, HSBC, TCRB, TMN (2026-11-15, from `TrueMoney.png`) | github.com/casperstack/thai-banks-logo `icons/` | open set, no licence file |
| SCBT, EXIM, SMED | supplied by the owner | — |
| BNP, BOFA (`boa.svg`), DB, JPM, MEGA, SMBC (2026-11-15) | github.com/omise/banks-logo `th/`, white mark on the colour in its `banks.json` | MIT, notice below |
| BOC, IOB, MIZUHO, OCBC, RHB, SMTB, SPAY (2026-11-15) | Wikimedia Commons: Bank of China Holdings Logo.svg, Indian Overseas Bank Logo.svg, Mizuho Bank logo.svg, Logo-ocbc.svg, RHB Logo.svg, Sumitomo Mitsui Trust Bank Logo.svg, Shopee logo.svg (the mark only, cropped from the wordmark) | public domain (as marked on Commons) |
