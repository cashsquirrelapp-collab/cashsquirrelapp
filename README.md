## แผนผังโฟลเดอร์

```
frontend/        หน้าเว็บ
  src/app/         โครงแอปหลัก (App.tsx), เส้นทางหน้า, หน้าโหลด
  src/features/    แต่ละฟีเจอร์ (รายการด้านล่าง)
  src/components/  ชิ้นส่วนที่ใช้ร่วมกัน รวมถึงมาสคอตน้องกระรอก
  src/i18n/        ข้อความภาษาอังกฤษ (ข้อความหลักเป็นภาษาไทย)
  public/          ไอคอน รูปภาพ หน้านโยบาย ฟอร์ม LINE (LIFF)
backend/         API หลังบ้าน
  src/handlers/    ทางเข้า API แต่ละตัว เช่น auth, data, billing, line-webhook, vault
  src/services/    งานหลัก: LINE, รับชำระเงิน, รายงานรายเดือน, โควตาเอกสาร, ลบบัญชี
  src/security/    คุกกี้, สิทธิ์ผู้ดูแล, ตรวจคำขอที่เข้ามา
cloudflare/      Worker ของเว็บจริงและงานตั้งเวลา (cron)
shared/          โค้ดที่หน้าเว็บกับหลังบ้านใช้ร่วมกัน: ภาษี, หัก ณ ที่จ่าย, ราคา Pro, ตรวจข้อมูล
database/        SQL ของ Supabase: 24 migration และสคริปต์ตรวจความปลอดภัย
supabase/        migration ชุดของ Supabase CLI
migration/       เครื่องมือช่วงย้ายจาก Vercel ไป Cloudflare
scripts/         สคริปต์สร้างไอคอน, เมนู LINE, หน้าแลนดิ้ง, ตรวจก่อนปล่อยงาน
tests/           เทสหลังบ้าน (*.test.ts) และเทสบนเบราว์เซอร์ (tests/e2e)
```
