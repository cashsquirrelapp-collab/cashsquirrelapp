# เนื้อหาแพ็กเกจส่งขึ้นเว็บ

รวม source ของ frontend, backend, shared types, API entry point, migrations 001–005, tests, Vercel configuration, package lock, คู่มือ deployment และเอกสารส่งมอบ `HANDOFF.md`

แพ็กเกจไม่รวม:

- `.env`, `.env.local` และ credentials จริง
- `node_modules`, build output และ caches
- screenshots, Playwright traces และ test results
- editor/agent configuration และ Git metadata
- generated database files หรือ logs

ผู้รับไฟล์ต้องสร้าง environment variables ในระบบ hosting เองตาม `DEPLOYMENT.md`
